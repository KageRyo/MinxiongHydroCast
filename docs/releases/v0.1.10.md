# MinxiongHydroCast v0.1.10 — Protocol Verification Security Update

Release date: 2026-11-15

Release tag: `v0.1.10`

GitHub Release name: `MinxiongHydroCast v0.1.10`

## Highlights

- The protocol source archive attached to this release pins certifi 2026.10.23 and setuptools
  84.1.0 in `requirements-protocol.lock`. The v0.1.9 archive pinned certifi 2026.7.22 and
  setuptools 80.10.2, which are affected by GHSA-6q48-6c7w-9gw2 (critical: certifi still trusted
  emSign root CAs whose intermediate CA keys were compromised), GHSA-h35f-9h28-mq5c and
  GHSA-xmj3-9gf7-h52w (setuptools). Use this archive instead of the v0.1.9 archive when you
  reproduce protocol verification.
- The coverage demo writes its synthetic fixtures to fixed local paths instead of paths read back
  from the generated inventory. The demo output is unchanged.

## Compatibility and safety

This is a dependency and maintenance patch. The CLI, JSON API, report formats, data-root content,
runtime package dependencies and the independent `dataset-protocol-v0.2.0` release are unchanged.
The `dev` extra now includes Pillow for the demo GIF frame tests.

## Verified release evidence

- 473 tests pass, alongside Ruff, CI-scoped Pyright and public contract validation.
- The wheel and source distribution build, and the installed-wheel smoke test passes.
- A hash-checked, binary-only install of `requirements-protocol.lock` resolves certifi 2026.10.23
  and setuptools 84.1.0. The protocol archive builds and verifies, and the 70 reconstruction tests
  pass from the extracted source.

python -m pip install --upgrade minxiong-hydrocast==0.1.10
