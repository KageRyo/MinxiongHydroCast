# MinxiongHydroCast v0.1.7

Release date: 2026-10-20

Release tag: `v0.1.7`

GitHub Release name: `MinxiongHydroCast v0.1.7`

This patch makes the dataset protocol's committed source and synthetic reconstruction path
available as a verified GitHub release asset, and fixes observation-time/native-datum alignment in
QPE/gauge diagnostics. The independently published
[label-free protocol](dataset-protocol-v0.2.0.md) completes the source-method deliverable without
manual annotations. This software release does not certify the official corpus or forecast readiness.

## Included

- `scripts/protocol_archive.py build` creates a deterministic archive from a selected Git commit.
- `verify` checks every included file, the strict manifest and its pinned checksum, source metadata,
  safe member paths, and publication blockers before optional extraction to a new directory.
- The archive includes source, protocol documentation, the formal manifest, validators, tests,
  and synthetic fixtures. It excludes runtime reports, official captures, generated tensors,
  model weights, credentials, and private event review catalogs.
- CI and the release workflow run the extracted-source synthetic reconstruction tests. The
  protocol asset is kept separate from the Python wheel/sdist and PyPI publication.
- Changes since v0.1.6 also include the public documentation site, public-contract checks,
  event-discovery integrity improvements, and kernel-backed discovery locking.
- QPE/gauge reports require timezone-aware matching observation end times and the same declared
  geographic datum. Coordinate pairs are selected together; production times cannot replace
  observation times. Unknown metadata and unsupported product/units are rejected.
- Public formal frame/source/build inventories retain exact checksums and the legacy acquisition
  limitations. The label-free policy retains unknown weather regimes and the unchanged split.
- README and roadmap identify proposed rolling backtests, event replay and archive coverage;
  these future features are not presented as implemented.

The release workflow attaches `minxiong-hydrocast-protocol-v0.1.7.tar.gz` and `SHA256SUMS` after
verification. The inner `PROTOCOL_ARCHIVE.json` records the exact source commit/tree and blocked
dataset/forecast state; the inner checksum inventory covers all included files. Checksum verification
detects modification, not authorship; obtain the asset from the trusted repository release.

## Separate protocol citation and retained limitations

The protocol has its own `dataset-protocol-v0.2.0` tag, exact inventory and dataset citation.
The root `CITATION.cff` describes software v0.1.7. Neither protocol publication nor radar research
waits for unavailable manual labels. Historical QPE gaps, old `verify_tls=false`, missing legacy
command/revision and the existing model/operational gates remain disclosed. See the
[acceptance record](../dataset_acceptance.md) and
[dated deployment evidence](../deployment_status.md).
