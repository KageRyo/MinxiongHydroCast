# MinxiongHydroCast v0.1.9

Release tag: `v0.1.9`

Released: 2026-10-21. This patch release refines the operator dashboard, offline event replay
and archive coverage report introduced in the existing observation and research workflows.

## Changed

- Show common observation columns first, with complete raw records and source checks in
  expandable details. Distinguish snapshot creation, station observations and collection time.
- Use consistent Traditional Chinese labels, readable measurement units and restrained status
  colors. Unevaluated shadow checks remain neutral; publisher attribution comes from the source.
- Compact replay controls so radar plots appear in the mobile first screen. Label the slider as
  an ordered frame selector and disclose gaps between stored frames. Verified, pending and
  invalid results use distinct text and colors.
- Prioritize expected, structurally usable, confirmed missing and unchecked coverage slots.
  Keep file-size/checksum counts and diagnostic codes available in detailed results.
- Package the operator HTML as a resource and refresh the README screenshot and usage docs.

## Fixed

- Catch manual and automatic API refresh failures, restore the refresh control, and explicitly
  identify potentially retained data after a failed status read.
- Duplicate archive slots with deferred integrity checks show pending checks instead of failed
  size/checksum checks. Already verified integrity flags remain visible; duplicates stay unusable.

## Validation and scope

474 tests pass, alongside Ruff, CI-scoped Pyright, strict documentation/link checks and installed
wheel smoke tests. Chromium checks cover desktop and narrow mobile layouts, raw-record disclosure,
API failure/recovery, pending scores, playback/Escape and irregular frame gaps.

JSON API and JSON/plain-text report contracts retain their existing behavior. Offline replay
still uses exact script/style hashes, and coverage remains script-free. Forecast publication and
notification permissions retain their acceptance gates. The independent
`dataset-protocol-v0.2.0` release remains unchanged.

## Install and try

```bash
python -m pip install --upgrade minxiong-hydrocast==0.1.9
mhc event replay --demo --output /tmp/hydrocast-replay-v019.html
mhc data archive-coverage --demo --format html --output /tmp/hydrocast-coverage-v019.html
```

Open the HTML files directly in a browser; choose new filenames on repeated exports. For the
operator dashboard, collect a demo snapshot with `mhc collect --mode demo --once`, then run
`mhc serve --host 127.0.0.1 --port 8080` and open <http://127.0.0.1:8080/>.

See [operator usage](../operational_use.md), [event replay](../event_replay.md) and
[archive coverage](../archive_coverage.md) for interpretation and data-source details.
