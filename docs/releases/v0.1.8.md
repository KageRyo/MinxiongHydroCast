# MinxiongHydroCast v0.1.8

Release tag: `v0.1.8`

Released: 2026-10-21. This software release packages the three label-free research workflows
tracked in #58, #59 and #60. The independent `dataset-protocol-v0.2.0` release remains unchanged.

## Added

- `mhc model rolling-backtest`: retain input-only Persistence/Optical Flow forecasts and score
  later radar observations with shared masks, per-origin/lead metrics and immutable resumable caches.
- `mhc event replay`: export a standalone offline observation/forecast/error explorer with
  playback, model/lead selection, saved scores and optional segregated hourly QPE/gauge context.
- `mhc data archive-coverage`: deterministic JSON/table/offline HTML reports separating expected,
  present, size/checksum-verified and structurally usable native radar/QPE frames. Includes gaps,
  duplicates, quality drift, bounded checks and classified source failures.
- Credential-free native-schema demos for both offline views, shipped inside the wheel and
  exercised by installed-package smoke checks.

## Integrity and scope

Research artifacts remain outside project source. Reads are constrained to the configured data
root, caches and source hashes are verified, and report exports never overwrite existing files.
The replay uses exact script/style hashes; coverage uses script-free semantic HTML. Missing,
corrupt, duplicate and unchecked data remains visible. Recorded HTTP 404 results do not imply
an upstream retention policy. No network retry, formal split edit, manual annotation requirement
or operational publication-gate relaxation is introduced.

## Install and try

```bash
python -m pip install --upgrade minxiong-hydrocast==0.1.8
mhc event replay --demo --output /tmp/hydrocast-replay.html
mhc data archive-coverage --demo --format html --output /tmp/hydrocast-coverage.html
```

Choose new output filenames on repeated exports. Open the HTML files directly in your browser.
For preserved official data, consult [rolling backtests](../rolling_backtests.md),
[event replay](../event_replay.md) and [archive coverage](../archive_coverage.md).
