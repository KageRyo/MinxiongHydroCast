## Rolling radar backtests

`mhc model backtest-manifest` reads the local event discovery catalog and exports recorded radar
frames and checksums for Persistence and Optical Flow backtests. Repeated exports add newly
captured frames and preserve previously exported frame identities. The exporter keeps the
earlier candidate when selected observation windows overlap.

The [rolling-backtest guide](../rolling_backtests.md) includes the manual commands and an optional
systemd drop-in to refresh the manifest before each scheduled run. The backtest groups its
outputs by configuration, including the installed package version, so an upgrade uses a new
configuration ID and retains the earlier results on disk.

## Documentation

The [Traditional Chinese quick start](../getting_started.md) includes offline replay and archive
coverage demos that use synthetic data. The homepage and API guide explain the model results,
observation timestamps and service status in plainer language.

## Scope

The exporter supplies data for research backtests. Forecast publication, risk notifications and
formal dataset changes remain subject to their existing acceptance criteria. The independent
`dataset-protocol-v0.2.0` release remains separately citable.

## Install

```bash
python -m pip install --upgrade minxiong-hydrocast==0.1.11
mhc model backtest-manifest --help
```
